This is an interactive chart of the Weekly NBA Power Rankings

# [See it in action!](https://nathanemyers.github.io/nba-weekly-power-rankings/)

## Local production preview

To check the site exactly as GitHub Pages will serve it, including the `/nba-weekly-power-rankings/`
sub-path:

```bash
npm run lint
npm run build
npm run preview
```

`npm run preview` prints a URL ending in `/nba-weekly-power-rankings/`; open it to confirm the
chart and every season load with no failed requests before merging.
