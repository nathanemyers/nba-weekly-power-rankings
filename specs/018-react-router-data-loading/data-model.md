# Data Model: URL Routing and On-Demand Season Data

## SeasonIndexEntry (new, bundled)

One per available season, newest first. Generated by `scripts/build-rankings.mjs` and validated by
`SeasonIndexSchema` at module load.

| Field | Type | Rule |
|-------|------|------|
| `name` | string | non-empty (a `^\d{4}-\d{2}$` rule was dropped so test fixtures can use names like `long`) |
| `source` | `DataSource` (`'nba' \| 'espn'`) | same enum as `SeasonDataSchema.source` |
| `champion` | `Team` (optional) | present only when the season has a champion |

- `latestSeason` = `seasonIndex[0].name` (the default for `/` and for unknown seasons).
- Entries that fail validation are dropped with `console.error`. An empty index renders the
  "No season data available" message.

## SeasonFile (existing, lazy)

The raw JSON per season, unchanged on disk. It is parsed with the existing `SeasonDataSchema` when
it arrives. Its loader is `seasonLoaders[name]: () => Promise<{ default: unknown }>`.

## Season (existing derived type, moved)

Produced from a valid SeasonFile by the existing transformation in `loadSeasons.ts`
(`name, source, teams: TeamRankings[], maxWeek, completed, champion?`). The transformation moves to
`src/data/seasonData.ts` and works on one season at a time.

## Season cache (new, in memory)

`Record<string, Promise<Season>>` at module level. The flow is:

1. `loadSeason(name)` returns the cached promise if it exists.
2. Otherwise it calls `seasonLoaders[name]()`, parses the result, transforms it, and caches it.
3. A rejected promise (failed download or failed validation) is removed from the cache, so a later
   visit retries.

## Route params

| Route | Param | Validation | On failure |
|-------|-------|------------|------------|
| `:season` | `season` | must equal a `seasonIndex` name | `redirect('/' + latestSeason)` |
| `teamHistory/:team` | `team` | `z.enum(Team)` on `team.toLowerCase()` | 404 → `RouteError` "Team not found" |

## Loader data

| Route id | Shape |
|----------|-------|
| `season` | `{ season: Promise<Season> }` |
| `teamHistory` | `{ team: Team, seasons: Promise<Season[]> }` (seasons that failed are skipped and logged) |

## Redux state (after)

`{ chart: { zoomedOut, startWeek, endWeek, pinnedTeams } }` only. Selectors that need the season
length take `maxWeek: number` as an argument. `seasons` and `UI` slices are removed.

## State transitions

- **Season picker change**: `setPinnedTeams([])`, then `navigate('/' + name)`. This adds a history
  entry.
- **Team history button**: `navigate('/teamHistory/' + pinnedTeam)`.
- **Team history card click**: `setPinnedTeams([team])`, then `navigate('/' + season)`.
- **Back/Forward**: the URL changes and loaders run. Redux is untouched.
